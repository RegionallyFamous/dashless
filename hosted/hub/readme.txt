== Description ==

Dashless Hub provides the account, authentication, billing, provisioning, and
ChatGPT connection services for a Dashless-hosted WordPress installation.

This plugin is distributed as part of the Dashless hosted service and is not a
general-purpose WordPress.org directory plugin.

== Installation ==

Install the complete release ZIP supplied by Dashless. The release includes
the Composer dependencies and ChatGPT adapter required by the plugin.
